The <color=yellow>Deliveries</color> tab shows incoming cargo at the <color=orange>current port</color> that your character can access.

<size=5>●</size> Select a shipment to see its origin, contents, arrival time, and status.
<size=5>●</size> While it is <color=yellow>In Transit</color>, Open Delivery is unavailable.
<size=5>●</size> When its status is <color=yellow>Delivered</color>, click <color=yellow>[Open Delivery]</color>.
<size=5>●</size> Chests appear near the Port Manager with the delivered items inside.
<size=5>●</size> Empty all the chests to complete the delivery. Clear existing cargo before opening another delivery.

To track cargo leaving this port, use <color=yellow>Shipments</color>.
