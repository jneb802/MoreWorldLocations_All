The <color=yellow>Receive</color> tab shows incoming shipments at the <color=orange>current port</color> that you can access.

<color=orange><b>Collecting Cargo</b></color>
<size=5>●</size> Select a shipment to see its origin, contents, arrival time, and status.
<size=5>●</size> While cargo is <color=yellow>In Transit</color>, wait for it to arrive.
<size=5>●</size> When its status is <color=yellow>Delivered</color>, select it and click <color=yellow>[Open Delivery]</color>.
<size=5>●</size> Chests appear near the Port Manager with the delivered items inside.
<size=5>●</size> Empty all the chests to complete the delivery. Clear existing cargo before opening another delivery.

To track cargo leaving this port, use <color=yellow>Send → Outgoing</color>.
