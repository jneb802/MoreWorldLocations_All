The <color=yellow>Cargo</color> tab combines incoming and outgoing shipments at the <color=orange>current port</color> in one list. It only shows shipments your character can access.

<color=orange><b>Track Cargo</b></color>
<size=5>●</size> <color=yellow>From [port]</color> identifies incoming cargo. <color=yellow>To [port]</color> identifies outgoing cargo.
<size=5>●</size> Select any shipment to see its origin, destination, contents, arrival time, and status in the same detail view.
<size=5>●</size> Cargo sent from this port can be collected at its destination, not here.

<color=orange><b>Collect Cargo</b></color>
<size=5>●</size> Select an incoming shipment. While it is <color=yellow>In Transit</color>, Open Delivery is unavailable.
<size=5>●</size> When its status is <color=yellow>Delivered</color>, click <color=yellow>[Open Delivery]</color>.
<size=5>●</size> Chests appear near the Port Manager with the delivered items inside.
<size=5>●</size> Empty all the chests to complete the delivery. Clear existing cargo before opening another delivery.

To send new cargo, choose a destination in <color=yellow>Ship</color>.
